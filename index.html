Не перезапускати через збій партнера

Якщо DPD недоступний, хочу щоб система повторила запит сама — а не показувала JSON-помилку.

Вставити адресу одним рядком

Клієнти дають адресу «вул. Франка, 15б, кв. 4». Хочу вставити це одним полем — система розбере сама.

GLS — Masový import zásilek (CZ)
✅ Успіх Import successfully processed Зелений статус після завантаження. Чисто, без зайвих деталей. Жодних технічних кодів — лише підтвердження.
❌ Помилка Import error: items are missing GLS чітко вказує рядок і поле: «Line 2: Street of the beneficiary», «Line 3: Surname». Точно і зрозуміло — жодних технічних кодів.
💡 Пресети Parcel dimensions: S-Pack / L-Pack GLS пропонує типорозміри (S-Pack 5×10×20 cm, L-Pack up to 20 kg) — одним значенням замість 3 окремих колонок Д×Ш×В.
Zásilkovna (Packeta.com) — Import zásilek (EN)
📁 Upload Import parcels file Простий екран завантаження з чітким блоком інструкцій: дозволені формати (CSV, XML, XLS, XLSX, ODT) та вимога кодування UTF-8.
✅ Шаблон Template selector — dropdown Після вибору файлу — dropdown для вибору шаблону. Клієнт вказує свій формат колонок, а система адаптується під нього.
❌ Виправлення Editing of unfinished parcels При помилці — форма з виділеними червоним проблемними полями. Текст помилки конкретний: «The assigned tracking number is outside the range». Навіть тут видно Scientific Notation у телефоні (4,20123E+11).
📋 Список Unfinished plots — всі помилкові рядки Окрема сторінка з незавершеними посилками. Червоним виділено помилкові рядки. Масові дії через «Group actions: Execute».
